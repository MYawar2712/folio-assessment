# Reviewer Guide

## Live product

https://folio-assesment.vercel.app

## Credentials

No login is required. The app uses a seeded personal workspace for this MVP.

## Sharing demonstration

1. Open any document.
2. Use **View as → Owner · Muhammad**.
3. Click **Share** and select `alex@ajaia.com`.
4. Click **Send invite**.
5. Use **View as → Shared user · Alex** to verify Alex can see the shared document.
6. Use **View as → Other user · Maria** to verify Maria cannot see it.

## Import demonstration

Use **Import a document** and select `test-import.md` from the repository. Supported formats are `.txt` and `.md`.
